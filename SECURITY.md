# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly through GitHub's private vulnerability reporting feature.

To report:
1. Open the repository on GitHub.
2. Navigate to the Security tab.
3. Select Report a vulnerability.
4. Provide a clear description and steps to reproduce the issue.

## Please Do Not

- Publish security vulnerabilities in public issues before they are addressed.
- Share passwords, API keys, access tokens, or other secrets.
- Commit credentials, private keys, or environment files to the repository.

## Security Expectations

All contributors must:
- Keep credentials and secrets outside source control.
- Use environment variables for sensitive configuration.
- Validate and sanitize untrusted input.
- Follow secure authentication and authorization practices.
- Review dependencies for known vulnerabilities.
- Report suspected security issues responsibly.

## Scope

This policy applies to the MAira Backend repository and its associated
backend services.
